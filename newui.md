Act as a Senior UI/UX Designer and Frontend Developer with extensive experience designing modern, intuitive, and visually polished dashboard-based web applications.

I want to redesign the UI of my existing web application because the current interface feels incomplete, lacks visual refinement, and could benefit from a more professional and well-structured layout.

I will provide:

Current UI: A screenshot or the existing application code.

Reference Image: A visual reference that represents the design direction I want to achieve.

Objective

Redesign the existing dashboard UI to closely match the visual style, layout, spacing, and overall design language of the reference image while improving usability, visual hierarchy, and consistency.

Key Design Requirements

1. Fullscreen Dashboard Layout

Remove the outer border, framed container, or card-like wrapper surrounding the entire dashboard.

Make the dashboard occupy the full available viewport width and height.

Create an edge-to-edge application layout that feels natural, modern, and immersive.

Ensure the sidebar, header, main content, and other existing sections fit seamlessly into the fullscreen layout.

Maintain appropriate padding and spacing within individual sections without adding an outer boundary around the entire application.

2. Follow the Reference Design

Analyze the reference image carefully before making changes.

Replicate its design language, visual hierarchy, spacing, alignment, typography, component styling, and overall aesthetic wherever appropriate.

Adapt the reference design to the existing application's content and components rather than copying elements that do not fit the application.

Ensure the final UI feels cohesive, polished, and production-ready.

3. Improve Visual Hierarchy and Layout

Identify areas of the current UI that feel cluttered, empty, inconsistent, or visually unbalanced.

Improve spacing, alignment, padding, margins, and component grouping.

Refine the appearance of cards, tables, forms, buttons, navigation elements, status indicators, and other existing UI components.

Establish a clear visual hierarchy so users can quickly identify important information and actions.

Use consistent border radii, shadows, borders, colors, and typography throughout the interface.

Avoid unnecessary visual elements, excessive borders, and inconsistent spacing.

4. Preserve All Existing Functionality — CRITICAL

This is strictly a UI/UX redesign, not a feature update or application rebuild.

Do not add, remove, rename, or modify any existing features.

Do not change business logic, calculations, workflows, or application behavior.

Preserve all existing buttons, forms, modals, dropdowns, navigation links, filters, search functionality, and interactive elements.

Maintain all existing API integrations, database connections, authentication flows, and data handling.

Preserve existing IDs, CSS selectors, JavaScript event listeners, component props, and backend integrations wherever they are required for functionality.

Do not replace functional components with static mockups or placeholder content.

Do not change the technology stack or introduce unnecessary dependencies.

Make changes only to the presentation layer unless a minimal structural adjustment is required to achieve the new layout.

5. Responsive Design

Ensure the redesigned dashboard works correctly on desktop, laptop, tablet, and mobile screens.

Prevent horizontal overflow, overlapping elements, broken layouts, and clipped content.

Maintain usability across different viewport sizes while preserving all existing functionality.

Implementation Instructions

First, inspect the existing codebase and understand its current layout and component structure.

Review the reference image and identify the design principles that should be applied.

Identify the specific UI elements that need improvement.

Update the existing styles and layout with minimal changes to the underlying structure.

Reuse existing components and assets wherever possible.

Test the redesigned interface to ensure all existing features continue to work correctly.

Remove obsolete styling only when it is no longer required and doing so will not affect functionality.

Expected Result

Deliver a visually polished, modern, and professional dashboard that follows the reference image's design direction, uses the full available screen instead of an outer framed layout, and has a consistent visual hierarchy.

Final priority: Preserve 100% of the existing features and functionality while significantly improving the UI. The application should look redesigned, not rebuilt.

Before finishing, verify that the fullscreen layout works correctly, the reference design has been followed, and all existing interactions remain functional.
